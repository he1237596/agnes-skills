# Douyin AIGC 风格生成器

## 触发条件

当用户请求生成抖音/快手风格图片或视频时触发。支持多种抖音主流风格，输出 720p 左右画质，视频控制在 10 秒以内。

## 可用风格列表

| 风格 | 描述 | 适用内容 |
|------|------|----------|
| `古风变装` | 素人照片转古装美人，工笔画/汉服/国风元素 | 汉服、古装剧、国风内容 |
| `二次元化` | 真人照片转动漫/二次元风格，Cel-shading | 动漫爱好者、二次元内容 |
| `AI变身` | 真人脸变二次元少女/少年，反差感强 | 娱乐内容、个人展示 |
| `Pixar 3D` | 皮克斯风格 3D 渲染，大眼睛、Subsurface scattering | 宠物、人物、卡通内容 |
| `吉卜力动画` | 宫崎骏风格，手绘 2D，水彩纹理，柔和调色板 | 治愈系、风景、日常场景 |
| `拍立得复古` | 复古 Flash 胶片感，颗粒质感，暖色调 | 怀旧风、生活记录 |
| ` neon 赛博朋克` | 霓虹夜景，发光感，赛博朋克氛围 | 都市夜景、潮流内容 |
| `粘土动画` | 黏土材质 Stop-Motion 感，可爱柔和 | 萌宠、儿童内容、可爱风格 |
| `超写实电影` | 电影级光效，浅景深，真实感 | 产品展示、氛围视频 |
| `Lo-Fi 治愈` | 温暖色调，安静场景，loop 感 | 休息、睡眠、放松内容 |

## 执行流程

### 第一步：确认风格

如果用户没有指定风格，展示上面的风格列表让用户选择。如果用户指定了风格（中文或英文均可），直接进入对应流程。

**中文映射**：
- 古风 → `古风变装`
- 二次元 / 动漫 → `二次元化`
- AI 变身 / 变脸 → `AI变身`
- 皮克斯 / 3D 卡通 → `Pixar 3D`
- 吉卜力 / 宫崎骏 → `吉卜力动画`
- 拍立得 / 复古 / 胶片 → `拍立得复古`
- 赛博朋克 / neon / 霓虹 → `neon 赛博朋克`
- 黏土 / 粘土 → `粘土动画`
- 超写实 / 电影感 → `超写实电影`
- Lo-Fi / 治愈 → `Lo-Fi 治愈`

### 第二步：构建 Prompt

根据选定的风格和用户描述，生成详细的英文 prompt。

**图片 Prompt 模板**：
```
[风格关键词], [主题描述], [环境/背景], [光线描述], [构图], [情绪氛围], 
high quality, detailed, 720p, TikTok viral aesthetic
```

**视频 Prompt 模板**（含镜头运动）：
```
[风格关键词], [主题描述], [动作/动态], [镜头运动描述], 
[光线描述], [氛围], soft motion, viral video style, 720p
```

### 第三步：生成

**生成图片**：
- 调用 `agnes_aigc__text_to_image`，ratio 用 `9:16`（抖音竖屏）
- 画质默认 quality tier，不强制指定 size

**生成视频**：
- 调用 `agnes_aigc__text_to_video`
- width: `720`，height: `1280`（9:16 竖屏）
- num_frames: 根据帧率控制，10 秒内（如 30fps 用 301 帧，满足 8n+1）
- frame_rate: 30
- 视频必须 10 秒以内

**如果用户提供了参考图片（图生图/图生视频）**：
- 调用 `agnes_aigc__image_to_image` 或 `agnes_aigc__image_to_video`
- 保留参考图核心元素，只修改风格

### 第四步：输出

返回生成的图片和/或视频，并附带：
- 本地路径（从 structured_content 的 `local_path` 获取）
- 使用的风格名称
- Prompt 简要说明

## 关键注意事项

1. **抖音竖屏优先**：ratio 统一使用 `9:16`
2. **视频不超过 10 秒**：num_frames 控制，30fps 最多 301 帧（8×37+1=301）
3. **画质与速度平衡**：不强制指定 size，使用默认 quality tier 保证速度
4. **Prompt 用英文**：Agnes 模型对英文 prompt 理解更好
5. **风格关键词必须嵌入 prompt**：如 "Studio Ghibli style"、"Pixar 3D render" 等
6. **禁止使用真实人物肖像**：用户如果提供真人照片，只做风格迁移，不保留可识别身份

## 示例对话

用户："帮我生成一个古风变装的图片"
→ 调用 text_to_image，style: "古风变装"，ratio: "9:16"

用户："生成一个吉卜力风格的视频，画面是海边日落"
→ 调用 text_to_video，style: "吉卜力动画"，width: 720, height: 1280，num_frames: 301，frame_rate: 30

用户："把这张图转成二次元风格"（附带图片链接）
→ 调用 image_to_image，保留原图构图，添加二次元风格描述
